#  Alura Store - Análise de Eficiência Logística e Financeira

Este projeto foi desenvolvido como parte de um desafio de Data Science para analisar o desempenho de quatro unidades da rede Alura Store. O objetivo principal é identificar qual loja deve ser vendida para otimizar os recursos do grupo.

## 🚀 Tecnologias Utilizadas
* **Python 3.11**
* **Pandas**: Manipulação e tratamento de dados.
* **Matplotlib**: Geração de visualizações gráficas.
* **Jupyter Notebook / VS Code**: Ambiente de desenvolvimento.

## 📁 Estrutura do Projeto
* `AluraStoreBrasil.ipynb`: Notebook contendo toda a lógica de análise.
* `loja_1.csv` a `loja_4.csv`: Bases de dados utilizadas.
* `README.md`: Documentação do projeto.
